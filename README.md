# ZAVLO

ZAVLO Technologies is an interactive web experience presenting a concept for connected healthcare infrastructure, autonomous medical logistics, smart healthcare stations, and digital health systems.

## Overview

The website combines a technology-focused visual design with interactive 3D elements and structured product sections. Its content presents ZAVLO as a connected healthcare ecosystem linking logistics, physical infrastructure, digital health, and supporting engineering systems.

## Main Sections

- ZAVLO mission and healthcare vision
- Autonomous medical logistics
- Smart healthcare infrastructure
- Digital health systems
- Intelligent infrastructure and telemetry
- Technology and engineering presentation
- Contact and navigation sections

## Technology

The current site uses:

- HTML
- CSS
- JavaScript
- Three.js
- Tailwind CSS via CDN
- MapLibre GL for map presentation

## Interface

The website includes a responsive navigation system, interactive 3D hero content, animated section reveals, product presentation sections, responsive layouts, and accessibility-related states such as visible focus indicators and reduced-motion support.

## Current Status

ZAVLO is an active web project. The site and its presentation may continue to change as the concept and implementation are refined.
